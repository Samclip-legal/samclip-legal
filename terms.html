Servicio

Samclip AutoPublisher permite editar y organizar clips de video y, cuando las autorizaciones y permisos estén disponibles, enviarlos a TikTok mediante sus interfaces oficiales.

Uso permitido

Solo se debe procesar y publicar contenido propio o para el cual se tengan los permisos necesarios. El usuario debe cumplir los términos de TikTok, las normas de derechos de autor y la legislación aplicable.

Autorización de cuentas

El usuario debe autorizar expresamente la conexión de cada cuenta. Las funciones de publicación dependen de las aprobaciones, restricciones y disponibilidad de las API de TikTok.

Responsabilidad por contenido

El usuario es responsable de revisar títulos, etiquetas, privacidad, permisos y contenido antes de habilitar su publicación. La aplicación no garantiza alcance, monetización ni aprobación de publicaciones.

Disponibilidad y cambios

El servicio puede cambiar o interrumpirse por problemas técnicos o cambios de las plataformas externas.
